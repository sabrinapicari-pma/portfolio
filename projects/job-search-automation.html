Overview

What this workflow demonstrates

Weekly workflow that searches job opportunities, stores them in Google Sheets and prepares next application steps. It is documented as an operational system rather than a tool demo.

Problem

The repetitive business issue

Manual knowledge work creates inconsistent outputs, difficult handovers and repeated checks. The workflow turns that ambiguity into structured steps.

Solution

Modular automation design

The solution separates retrieval, transformation, AI reasoning, validation and output generation so each phase can be tested independently.

Technical details

Implementation notes

Uses HTTP requests, structured prompts, JSON parsing and spreadsheet-friendly outputs. JavaScript is used where workflow-native nodes need additional transformation logic.

Challenges

Reliability and structure

Key challenges include inconsistent source formats, multilingual content, model output validation and making failures visible enough to debug.

Lessons learned

Design for reviewability

Automation is strongest when every intermediate result can be inspected, corrected and explained to non-engineering stakeholders.

Technologies

Tools used

n8n, AI models, APIs, Google Sheets, HTTP requests, JavaScript, JSON processing and prompt engineering.
